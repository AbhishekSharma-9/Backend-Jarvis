**JARVIS Car AI** is a comprehensive automotive assistant ecosystem. It combines a responsive web dashboard with powerful backend services for driver safety, predictive maintenance, and intelligent voice interaction.

---

## 🚀 Key Features

### 🖥️ Frontend (Dashboard)
* **Interactive Chatbot**: AI-driven conversational interface for vehicle commands.
* **Real-time Monitoring**: Visual dashboard for car status.
* **Tata Integration**: Custom branding and UI themes.
* **Responsive Design**: Optimized for in-car displays and mobile devices.

### ⚙️ Backend (Core Logic)
* **Driver Monitoring**: AI modules to track driver alertness and safety.
* **Predictive Maintenance**: Algorithms to predict vehicle faults before they happen.
* **Main Backend**: Central server handling API requests and data flow.
* **JARVIS Engine**: Core logic for the AI assistant.

---

## 📂 Project Structure

### Frontend (`/UI`)
```text
├── chatbot/           # Chat interface logic
├── html/              # Web components
├── css/ & js/         # Styling and interactivity
├── preloader/         # Loading animations
├── TataXJarvis.png    # Branding assets
└── index.html         # Main Dashboard Entry
```
### Backend (/Server)
```text
├── driver-monitoring/       # Safety AI models
├── predictive-maintenance/  # Vehicle health algorithms
├── main-backend/            # Server configuration (server.js)
└── jarvis-backend/          # Assistant logic
```
## 🛠️ Getting Started
### 1. Setup Backend
Navigate to the backend directory and install dependencies:

```bash
cd main-backend
npm install   # or pip install -r requirements.txt (depending on your setup)
node server.js
```
### 2. Launch Frontend
Simply open index.html in your browser or run via a Live Server to connect to the backend API.
